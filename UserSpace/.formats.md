# UserSpace Format Reference
# When creating a NEW memory file, copy the matching template below.
# When the file already exists, follow its existing columns/fields.

## Classification (user keywords → filename)

| Keywords | File |
|----------|------|
| 记账/花钱/支出/消费/付钱/买了 | expenses.md |
| 待办/任务/提醒/日程/别忘了/记得 | tasks.md |
| 备忘/笔记/想法/记录/日记 | memos.md |
| 密码/账号/登录/注册 | passwords.md |
| 健身/运动/锻炼/跑步/游泳 | fitness.md |
| 优惠券/折扣/促销/满减 | coupons.md |

## Default Templates

### expenses.md — 记账本
| 日期 | 类别 | 金额 | 备注 |
|------|------|------|------|

### tasks.md — 待办事项
| 截止时间 | 发起日 | 任务 | 注意事项 | 状态 |
|----------|--------|------|----------|------|

### memos.md — 备忘录
```
## YYYY-MM-DD
content
```

### passwords.md — 密码本
| 平台 | 账号 | 密码 | 备注 |
|------|------|------|------|

### fitness.md — 健身记录
| 日期 | 项目 | 时长 | 备注 |
|------|------|------|------|

### coupons.md — 优惠券
| 平台 | 优惠内容 | 有效期 | 状态 |
|------|------|------|------|
